# rivermind

A poker study tool. Import your hand histories after a session, see how
your opponents play, check the equity of a spot, and get the decision
explained in plain words. A training mode lets you practise against bots.

It's for reviewing hands and training only. It never connects to a
real-money poker client.

## Status

Stage 1 of 6: hand history parser. See the roadmap in the issues of
`mayureshmandan/daily-dev`.

## Build

Needs Java 21. Maven comes with the repo.

```
./mvnw verify
```
